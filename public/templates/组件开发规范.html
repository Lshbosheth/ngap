1. 组件性能优化原则

在开发自定义组件时，需重点避免不必要的组件刷新，核心要求如下：

  • 仅在属性真正需要更新时触发组件刷新，避免无意义的重渲染
  • 杜绝频繁刷新组件，防止页面响应速度下降
  • 所有属性更新逻辑需做精准判断，非必要更新操作一律屏蔽

2. 组件文件结构与位置

2.1 文件目录

组件统一存放于 src/packages/ 目录下

2.2 组件文件夹结构

每个组件对应独立文件夹（示例名称：component），包含两个核心文件：

  • component.tsx：
    • 导出由 forwardRef 包裹的 React 组件
    • 返回组件实例化时展示的所有元素（含事件）
    • 通过 useImperativeHandle 暴露对外方法，基础方法包括 show、hide、update（需实现自动刷新逻辑），可扩展组件特有方法
  • Schema.tsx：
    • 默认导出组件配置对象，包含属性、样式、事件、数据配置
    • 优先复用现有配置项，无适配项时自定义配置
    • config 中配置组件所有属性并赋默认值，api 属性默认使用静态数据（可切换类型）

3. 组件拖拽逻辑处理

核心处理文件：editor.tsx

  • 新组件生成时的默认数据/方法需在此文件配置
  • 处理组件嵌套存储/单独存储逻辑
  • 示例场景：表单组件必须放入 Form 容器的校验逻辑

4. 画布工具操作逻辑

核心处理文件：TopBar.tsx

  • 支持组件上移、下移、复制、删除等操作的自定义逻辑扩展
  • 处理保存时的自定义逻辑（如数据格式转换）
  • 保存数据核心结构说明：
    • atomMap：组件全量信息对象数组（key 为组件 ID，value 为组件完整信息）
    • componentList：组件顺序数据（仅含 componentid、componentType、position）
    • atomList：组件列表数组（保存时转字符串，查询返回为 JSON 格式）

5. 右侧设置界面 - 样式配置

核心处理文件：components/StyleConfig/StyleConfig

  • 通用样式直接复用现有组件
  • 自定义样式通过 pageStore 的更新方法修改组件样式信息
  • 特有样式需在 pageStore 新增更新方法，在 StyleConfig 中调用

6. 右侧设置界面 - 属性配置

核心处理文件：components/SetterRender/SetterRender

  • 复用现有属性类型：直接设置组件 type 为对应类型（Title、Input、InputPx、TextArea、InputSelect、Switch、Select、Radio、InputNumber、RadioGroup、ColorPicker、Slider、Variable、function、Icons）
  • 新增属性：在文件中扩展对应类型及配置信息

7. 右侧设置界面 - 事件配置

核心处理文件：component/EventConfig/EventConfig

  • 通用事件无需修改此文件逻辑
  • 自定义事件/方法：在组件 Schema.ts 的 methods 属性中新增，事件流可直接调用

8. 右侧设置界面 - 数据配置

核心处理文件：component/ApiConfig/ApiConfig

  • 支持数据类型：静态数据、接口请求、动态变量
  • 数据更新流程：通过 pageStore 更新数据 → 更新组件 → 组件内实现内容渲染（在 component.tsx 中完成，与通用逻辑一致）

9.1 核心数据结构（pageStore）

复制
{
  userInfo: UserInfoStore;
  mode: 'edit' | 'preview'; // 编辑/预览模式
  theme: 'light' | 'dark'; // 主题
  selectedElement: { type: string; id: string } | undefined; // 选中组件
  isUpdateToolbar: boolean; // 更新遮罩
  isEdit: boolean; // 页面是否编辑
  page: {
    id: number;
    name: string;
    remark: string;
    projectId: number;
    isPublic: 1 | 2; // 公开状态
    stgState/preState/prdState: 1 | 2 | 3 | 4; // 环境状态：1-未保存 2-已保存 3-已发布 4-已回滚
    stgPublishId/prePublishId/prdPublishId: number;
    previewImg?: string;
    userId: number;
    userName: string;
    pageData: {
      config: { // 页面配置
        props: any;
        style: React.CSSProperties; // 页面样式
        scopeCss: string; // 作用域CSS
        scopeStyle: React.CSSProperties; // 作用域样式
        events: EventType[]; // 事件
        api: { // 数据接口
          sourceType: 'json' | 'api';
          id: string;
          source: any;
          sourceField: string | { type: 'variable' | 'static'; value: string };
        };
      };
      events: Array<{ name: string; value: string }>; // 页面事件
      apis: { [key: string]: ApiType }; // 全局接口
      elements: ComponentType[]; // 组件列表
      elementsMap: { [key: string]: ComponentType }; // 组件映射
      variables: PageVariable[]; // 页面变量
      variableData: { [key: string]: any }; // 变量数据
      formData: { [key: string]: any }; // 表单数据
      interceptor: { // 全局拦截器
        headers?: { key: string; value: string }[];
        timeout: number;
        timeoutErrorMessage: string;
        requestInterceptor?: string;
        responseInterceptor?: string;
      };
    };
  };
}
